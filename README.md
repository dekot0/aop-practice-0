### Відповіді на контрольні питання:

1. * Чим комплект розробника (JDK) відрізняється від середовища виконання (JRE)?
* JDK(Java Development Kit) - набір інструментів для створення программ. 
* JRE(Java Runtime Environment) - ця версія містить тільки віртуальну машину для запуску вже готових программ. 

2. * Яке призначення змінної середовища PATH і чому після її зміни потрібно відкривати нове вікно командного рядка?
* PATH - список папок, де Windows шукає програми, коли ви викликаєте їх за назвою в терміналі
* Нове вікно потрібне тому, що в терміналі залишается старий хєш(або знімок). Щоб термінал працював з новими змінами треба перезапустити його. 

3. * Що означає позначення LTS стосовно версії JDK?
* LTS(Long Term Support) це стабільна версія в якій компанія буде оновлювати безпеку протягом багатьох років. 

4. * Які функції виконує компілятор javac, а які — команда java?
* javac це компілятор який перетворює код в зрозумілий для машини байт-код. 
* java це команда запуску віртуальної машини. Ця ВМ (JVM) виконує файл(з кодом).

5. * Чим система контролю версій Git відрізняється від сервісу GitHub?
* Git це программа яка веде історію змін файлів. 
* GitHub це платформа на якій люди можуть викладувати свої проекти. 

6. *  Що таке коміт і які дані він містить, окрім змісту файлів?
* Коміт - збережений "знімок" стану проекта в Git. 
* Окрім коду, він містить також ім'я та пошту автора, дату та час створення, текстовий коментар. 

7. * Навіщо параметр user.email у Git має збігатися з поштою облікового запису GitHub?
* Щоб GitHub зміг роспізнати автора Коміту. 

8. * У чому полягає відмінність між закритим і відкритим ключами та який із них передається на сервер GitHub?
* Закритий ключ це той що лежить тільки на пристрої користовача, він не виходить в інтернет. Це як ключ від замка.
* А ось відкритий ключ це скоріше замок, замок який відправляють на сервер GitHub. Таким чином працює в цілому інтернет. 

9. * Чому автентифікація за SSH-ключем вважається безпечнішою за введення пароля?
* Пароль можна перехопити через фішинг, віруси, "людина по середині". А SSH ключ шифрується, тим самим його неможливо взломати брутфорсом. 

10. * Що захищає парольна фраза ключа, якщо відкритий ключ і так є публічним?
* Ця фраза подрібна для шифровки закритого ключа котрий лежить на пристрої. 
* Якщо хтось отримує доступ до пристрою то він не зможе без ціїє фрази SSH не спрацює. 

11. *  Чим взаємодія з асистентом у командному рядку (Claude Code) відрізняється від діалогу з чат-ботом у браузері?
* Claude code знаходиться всередині проекту, він може передивлятися увесь зміст проекту й тому краще розумію що від нього потребується. 
* чат-бот в браузері знає тільки те що ми йому відправимо. Тому може бути проблема з розуміння ШІ що від нього потребується. 
* Хоча як показує практика, ШІ складновато навіть якщо їй усе разписати)

12. * За яких умов використання інструментів ШІ під час виконання завдань курсу є припустимим, а за яких - вважається порушенням академічної доброчесності?
* Припустимим є використання ШІ для рішення помилок, вивченя нових термінів, перевірка власного алгоритму.
* Порушенням вважається коли людина зробила УСЕ через ШІ й не може навіть відповісти за що відповідає те чи інше й як воно працює.

13. * Які переваги надає інтегроване середовище розробки (IDE) порівняно з текстовим редактором і компілятором, що запускаються окремо?
* Це программи які об'єднують все в одному: підсвічування помилок,автодопис коду, вбудований дебаггер й в один клік зв'язується з Git і терміналом.
* Також має велику бібліотеку з різними плагінами.
